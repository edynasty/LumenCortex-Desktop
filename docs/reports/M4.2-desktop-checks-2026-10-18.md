## 5. Risks and open items

- **Publication:** Desktop pins the unpublished Core commit `c731a7c`. Publish Core (M3.2 through M4.1 and `c731a7c`) before Desktop.
- The fingerprint changes with edits that publish no runtime event (for example, a user editing files in an editor). The Checks tab shows Core's view as of its last read and has a refresh button; it does not watch the file system.
- Artifact labels in the list rely on Core's order (log first, then diff for results that did not pass; `internal/evaluator` `run`). The viewer header uses the artifact's own `kind`.
- Pre-existing, unchanged: `gofmt -l app.go` reports blank-line issues that were present at baseline. The working-tree deletion of `frontend/dist/.keep` and the untracked `.lumencortex/`, `build/`, `frontend/wailsjs/` and binary are the owner's and are not committed.
